# 築47年木造アパート放置ゲーム：キャラクター＆ストーリー素材調査書

**作成日**: 2026-09-30  
**対象**: 築47年・風呂なし木造モルタルアパートの大家となり、だめで人間臭い住人たちの日常を眺める放置ゲーム（大人向け）  
**方針**: 暴力描写・性的に具体的な描写・差別的・嘲笑的な笑いを排し、昭和〜平成のペーソス（哀愁）、生活の匂い、愚かしくも愛おしい人間性を抽出する。

## 2. キャラクターの種類（全26種）

各キャラクターはアパートの一室に住み着き、固有の生活リズム、だめな癖、人生の分岐（うまくいく筋・うまくいかない筋）、部屋の装飾を持つ。

### 2-1. `ronin`：万年浪人生
- **表示名**: 万年浪人生
- **年齢幅**: 20〜23歳
- **生活時間**: 
  - 就寝: 04:00〜12:00（完全な昼夜逆転）
  - 外出: 13:00〜17:00（予備校の自習室、または古本屋・ゲーセン）
- **だめな癖の候補**:
  1. 勉強を始める直前に必ず部屋の模様替えや机の拭き掃除を始めて半日潰す。
  2. 深夜ラジオに熱心にネタハガキを投稿し、読まれると勉強そっちのけで歓喜する。
  3. 模試の判定が悪いと「問題の傾向が古い」と予備校のテキストのせいにする。
- **人生の筋（うまくいく筋）**:
  1. 参考書タワーを崩し、深夜の勉強部屋で隣人の生活音を励みに基礎問題を解き直す。
  2. 大家から夜食の差し入れ（おにぎり）をもらい、感謝のあまり机で泣き崩れる。
  3. 昼夜逆転を直し、最後の模試で念願のB判定を叩き出す。
  4. 二次試験当日の朝、住人一同に見送られて出陣し、見事補欠合格を勝ち取る。
  5. 学生街のアパートへ引っ越す日、大家に深く頭を下げて去っていく。
- **人生の筋（うまくいかない筋）**:
  1. 参考書の隙間に古本屋で買った漫画本を隠し持ち、現実逃避の読書に没頭する。
  2. 深夜のファミレスに入り浸り、ドリンクバーだけで朝まで友人と管を巻く。
  3. 親からの受験料振込をゲームと古着の衝動買いで半分使い込む。
  4. 受験前日に緊張のあまり知恵熱を出し、本命の試験を欠席する。
  5. 親から仕送りを打ち切られ、深夜のコンビニバイトを始めて予備校籍を失う。
- **部屋の装飾の候補**:
  1. 黄ばんだ赤本と全国大学案内（角が丸まっている）
  2. 「捲土重来」と墨で殴り書きされた半紙
  3. 卓上電気スタンド（傘にガムテープの補修跡）
  4. 飲みかけの栄養ドリンクの空き瓶タワー
  5. 壁に貼られた予備校の年間模試スケジュール表

  1. 窓際部署で誰にも頼まれない社内資料の整理を黙々と続け、過去の重要データを発掘する。
  2. アパートの若手住人の就職相談に乗り、久々に「人に頼られる喜び」を思い出す。
  3. 若手役員に過去の整理データが評価され、新設された顧問室へ異動が決まる。

- **人生の筋（うまくいかない筋）**:
  1. 会社の早期退職勧告の面談を引き延ばし、机でネットニュースを眺めて1日を終える。

  3. 衝動的に希望退職届を出し、退職金の半分を怪しい未公開株投資に突っ込む。
  4. 投資詐欺に遭って蓄えを失い、昼間からスーツ姿で公園のハトに餌をやるようになる。
- **部屋の装飾の候補**:
  1. くたびれた黒革のビジネスバッグ（角が擦れて白くなっている）
  2. 針金ハンガーに掛かったヨレヨレのワイシャツ3枚

  4. 100円ショップの老眼鏡と新聞のスクラップ帳
  5. 押し入れに隠された「定年後の生き方」の実用新書

## 4. この素材で特に強い人生の筋・ストーリーライン トップ10

住人同士の生活リズム、性格の欠点、共通の哀愁が交差することで生じる、放置ゲームとして特にエモーショナルで印象に残る強力なドラマライン10選。

### 第1位：万年浪人生とキャバクラ嬢「壁越しの合格夜食」
- **登場人物**: `ronin`（万年浪人生） × `hostess`（キャバクラ嬢）
- **世界観の型**: 『めぞん一刻』（壁の薄さ・モラトリアム） × 『深夜食堂』（夜更けの温もり）
- **あらすじの連鎖**:
  1. 昼夜逆転で深夜に起きている2人。薄い壁越しに、勉強のシャープペンの音と、帰宅したヒールの足音が互いの生活のBGMになる。
  2. キャバクラ嬢が仕事帰りにコンビニで買った肉まんやスープを、浪人生のドアノブに「受験生ファイト」のメモと共に掛け始める。
  3. 孤独に押しつぶされそうだった浪人生は夜食に涙し、深夜ラジオを封印して机に向かう。
  4. 迎えた合格発表の日、浪人生は補欠合格の通知を手にキャバクラ嬢に報告しようとするが、彼女は昼間のネイルスクールに通い始めて生活時間がすれ違う。
  5. 浪人生の退居日、ドアノブに「合格しました。ごちそうさまでした」の手紙とお礼の高級ハンドクリームが残される。
- **強い理由**:
  直接顔を合わせず「壁越し・ドアノブ越し」の間接的なやり取りだけで心の交流を描く奥ゆかしさがある。放置ゲームの観察画面で「隣り合う二部屋の灯りの明滅」だけでプレイヤーに物語を想起させ、最後に感情のカタルシスをもたらす。

### 第2位：情に脆い取り立て屋と窓際サラリーマン「屋上の黄昏缶酎ハイ」
- **登場人物**: `debt_collector`（取り立て屋） × `salaryman`（窓際サラリーマン）
- **世界観の型**: 『闇金ウシジマくん』（借金・取り立て） × 『深夜食堂』（男たちの背中）
- **あらすじの連鎖**:
  1. 会社で居場所を失い、帰宅恐怖症で駅前を徘徊してからアパートに帰る窓際サラリーマン。
  2. 街金で非情になりきれず、回収ノルマに追われて胃薬をかみ砕く取り立て屋。
  3. アパートの外階段で、互いに背中を丸めて安物の缶酎ハイを飲んでいるところで遭遇する。
  4. 取り立て屋が「会社があるだけ羨ましいよ」と愚痴り、サラリーマンが「君の仕事も身を削るね」と乾き物を差し出す。
  5. 人生に行き詰まった中年男二人が、互いの情けなさを笑い飛ばすことで少しずつ前を向き、取り立て屋は資格取得へ、サラリーマンは社内資料の整理へと歩み出す。
- **強い理由**:
  甘い恋愛ではない「世間に居場所のない大人の男同士の連帯と慰め」。社会の理不尽に揉まれて疲れたプレイヤー自身の心にも深く刺さるペーソスがある。
